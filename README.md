# car-simulator

![](/screenshots/front_view.png)

A Ray cast based car simulator built in UPBGE Game engine (version 0.44)


## Keyboard Controls

| Action | Key |
|--------|-----|
| Move forward | <kbd>W</kbd> |
| Turn left |  <kbd>A</kbd> |
| Turn right | <kbd>D</kbd> |
| Move reverse| <kbd>S</kbd> |
